Requality is a tool to manage requirements primarily to software. Requality automates basic requirements processes. Requality could be used as an initial requirements storage, as a framework to structure and attribute requirements presented as text documents (e.g. software standard documents).

Use cases:

  • structuring requirements (mark-up plain text into a hierarchical structure);
  • requirements attributing (attach some attributes sets to requirements);
  • team work (integration with popular version control systems: git, svn and others);
  • supporting requirements revisions;
  • authomatic requirements transferring when updating documents;
  • agile report generation system.
